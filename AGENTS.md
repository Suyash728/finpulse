## Architecture map
- `backend/app/main.py` — FastAPI routes; envelope `{success, data, error}` on every response
- `backend/app/examples.py` — openapi examples the stub routes return; delete entries as routes go live
- `backend/app/db.py` — Supabase client (service key, lazy import)
- `backend/app/engines/` — parse, normalize, categorize (CATEGORIES/ESSENTIAL), recurring, simulate,
  nudges, report, emailer. Pure Python; all rupee math lives here.
- `backend/app/agents/coach.py` — coach agent, plain function calling (spec: `agents/graph.md`)
- `backend/app/services/llm.py` — **the only place model calls happen** (3-tier router)
- `backend/app/services/trace.py` — per-run events -> SSE `GET /coach/{run_id}/events`
- `backend/app/seed.py` — demo profile, goals, budgets, sample file list
- `backend/samples/` — generated by `scripts/make_samples.py` ("Load sample case" = POST /ingest with these)
- `supabase/migrations/0001_init.sql` — schema (single user; RLS on, no policies; backend uses service_role)
- `frontend/src/app/{page,transactions,plan,coach,report}` — 5 tabs; `components/app-shell.tsx` (bottom tabs
  < md, sidebar >= md, theme toggle); `components/TracePanel.tsx`; `lib/api.ts` (typed envelope client)
- `frontend/src/app/manifest.ts`, `public/sw.js`, `public/icons/` — PWA
- `openapi.yaml` — frozen API contract (Prism mock: `npx @stoplight/prism-cli mock openapi.yaml -p 4010`)

## Hard decisions
- Agent = PLAIN FUNCTION CALLING, not LangGraph/CrewAI. Keep services/trace.py and the SSE trace panel;
  the coach emits one trace event per tool call {node: tool_name, status, tier_used, ms, args, result_summary}.
- Every rupee figure shown to the user is computed in Python. The LLM never does arithmetic.
- Categorization order: exact merchant rule -> normalized-merchant rule -> LLM with the user's last 20
  corrections as few-shot examples -> LLM alone. Every transaction stores cat_source (rule|ai|user) + confidence.
- ESSENTIAL categories: Rent, Utilities, Groceries, Medical, EMI, Insurance, Education. Never suggested as cuts;
  what-if may model them rising. If essentials > income, say so plainly and point to income or a human advisor.
- Securities guardrail: an intent check runs BEFORE the agent; stock/fund/crypto pick requests get a refusal
  plus an educational answer.
- Email via Resend (test sender to our own inbox), triggered by a button. No cron. No push notifications.
- PWA = app/manifest.ts + icons + a minimal service worker caching the app shell. No offline sync.
- Local GPU tier stays in llm.py but is not used for this event (cloud deploy is mandatory).
- Categories (fixed list): Rent, Utilities, Groceries, Medical, EMI, Insurance, Education, Dining, Food Delivery,
  Shopping, Travel, Entertainment, Subscriptions, Fuel, Transfers, Income, Investments, Other.

## UI
Mobile-first, information-dense, shadcn (new-york) + Recharts. Light/Dark toggle (next-themes, class strategy).
References: shadcn-fintech.vercel.app (grouped sidebar, stat tiles w/ delta, signed coloured amounts) and
studio-admin.arhamkhnz.com (KPI cards with delta badges, dense tables). Use theme tokens (`text-positive`,
`text-negative`, `bg-chart-1`...), never raw grays, so dark mode works.
